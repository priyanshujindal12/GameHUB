# 🎮 GameHub

GameHub is a browser-based gaming platform that brings multiple mini-games together in one interactive gaming hub.

The platform provides a central interface where users can browse and launch different games, view their game scores, and track their overall GameHub rating.

The project is built entirely with **HTML, CSS, and Vanilla JavaScript**, without React, backend services, or databases.

---

## ✨ Features

### 🏠 Landing Page
- Premium dark gaming-themed landing page
- GameHub branding
- Animated background effects
- Interactive "Start Playing" CTA
- Responsive design

### 🎮 Game Library
- Centralized game interface
- Multiple games available from one dashboard
- Game cards for easy navigation
- Game categories and game information
- Smooth hover and interaction animations
